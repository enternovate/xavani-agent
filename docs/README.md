# Documentation map

| Path | Holds |
| --- | --- |
| `docs/development/` | Test and contribution workflows. |
| `docs/reference/` | CLI, environment, and provider reference. |
| `docs/reliability/` | Reliability evidence, reviews, the parity report, and the release process. |
| `docs/security/` | Dependency baseline and security evidence. |
| `docs/release-notes-0.2.0.md` | Release notes for 0.2.0. |

The docs tree also holds per-release notes and per-cycle closure records.
Both live directly under `docs/` and follow the release or cycle name.

Root entry points:

- `SECURITY.md` — vulnerability reporting policy.
- `CONTRIBUTING.md` — how to contribute.
- `AGENTS.md` — rules for automated contributors.

Planning lives outside this tree. See `planning/README.md`.
