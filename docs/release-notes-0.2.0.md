# Xavani Agent 0.2.0 — Release Notes

"The Big Bang" — 2026-08-22

## Headline features

1. **Loop engine** — rerun tasks until a stop condition fires, with
   reflexion failure notes, runaway guards, and crash-safe resume.
   Watchdog mode (`/loop watch`) runs on the cron scheduler: silent
   ticks, alert on finish.
2. **Eval harness** — 21 categorized tasks; jsonschema/pytest/exit_code/
   llm_judge verifiers; p95 and per-category medians; flake detection;
   fingerprinted results; config leaderboard; regression gate.
3. **Advisor role** — a second model reviews every reply on its own
   context and appends [high]/[medium]/[low] notes inline.
4. **Agent hub** — live subagent roster with steer, kill, and revive.
5. **Approval gate hardening** — write journal with inverse-patch
   rollback (/revert), batch approval preview, dry-run mode,
   /permissions manager, audit log.
6. **RPC mode** — NDJSON-over-stdio protocol with answerable tool cards
   for embedders: `python3 -m xavani_cli.rpc_mode`.
7. **Workflow tooling** — atomic commit splitter with cycle rejection,
   cross-agent config importer with provenance comments, memory bank
   tools, deterministic macros, conflict resolver, SESSION_HANDOFF
   generator.
8. **CLI polish** — two new skins (xavani-terminal, xavani-ember),
   strict skin validation, doctor checks for the new data surfaces,
   activity-line formatter across loop/eval output.
9. **Eight workflow packs** — inbox-triage, meeting-notes,
   invoice-extraction, weekly-review, research-monitor, document-draft,
   expense-log, crm-lite. Skills index grows to 189.

## Requirements

- Python 3.11+ (enforced by install.sh and install.ps1)
- No new mandatory dependencies

## Upgrading from 0.1.x

- No configuration keys removed. New optional keys:
  - `model.roles.<role>` (default/smol/slow/plan/advisor)
  - `cron.script_timeout_seconds`
  - `display.skin` now accepts xavani-terminal and xavani-ember
- New data directories (created by installers and on first use):
  - `~/.xavani/loops/`
  - `~/.xavani/macros/`
  - `~/.xavani/memories/bank/`
  - `~/.xavani/scripts/`
- Messaging-platform slash menus stay under Slack's 50-command cap via
  curation; desktop-only commands remain reachable through `/xavani`.
