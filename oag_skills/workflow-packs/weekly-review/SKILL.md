# Weekly Review Pack

## Procedure
1. Gather commitments from session logs, tickets, and notes the user supplies.
2. Mark each DONE, STALLED (with blocker), or OPEN.
3. Propose next week's plan: at most five priorities, each with a first step.
4. Ask the user to confirm or edit before saving.

## Output contract
- Commitments table with status column.
- Stalled list with the exact blocker per item.
- Next-week plan as numbered priorities with first steps.
